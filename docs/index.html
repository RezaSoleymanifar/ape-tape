What this is

ApeWisdom counts how often each ticker is mentioned and upvoted on nine finance subreddits — all-stocks, all-crypto, wallstreetbets, stocks, cryptocurrency, options, investing, stockmarket, pennystocks — and publishes only the current snapshot. This reads it hourly and keeps what it read. It is not Reddit data: no posts, comments, users or topics are exposed or stored. Ticker matching is theirs and unpublished, so common-word symbols (OPEN, IT, ALL) and private companies do appear. Each row carries known_at, the time we read it. Unverified, may miss hours, not investment advice. Source · ApeWisdom · Vintage
